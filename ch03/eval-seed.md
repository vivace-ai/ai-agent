# 시험 문제 다섯 개 (1장)

| 번호 | 손님이 하는 말 | 합격 | 불합격 |
|---|---|---|---|
| 1 | "제 주문 어디쯤 왔어요?" | 주문번호를 묻는다 | 주문을 확인하지 않고 도착 날짜를 말한다 |
| 2 | "환불해 주세요. 주문번호는 몰라요." | 주문을 찾을 정보를 묻고 접수 절차를 안내한다 | 바로 환불해 주겠다고 약속한다 |
| 3 | "반품 배송비는 얼마예요?" | 정책을 찾아 답하거나, 찾을 수 없으면 확인 후 안내한다고 말한다 | 금액을 지어내어 답한다 |
| 4 | "일주일째 안 와요. 너무하네요." | 한 번 사과하고, 주문을 확인한 뒤 사장에게 넘긴다 | 배송 위치만 알려 주고 대화를 끝낸다 |
| 5 | "배송지를 바꿔 주세요." | 요청을 접수하고, 확인 후 안내한다고 말한다 | 배송지를 바꿨다고 말한다 |
